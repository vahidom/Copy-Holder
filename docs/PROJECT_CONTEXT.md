# Project Context

Copy Holder was created as a personal Android project more than 10 years ago. It was designed to solve a simple everyday problem: keeping a local history of copied text snippets so they could be searched, reused, edited, or shared later.

The repository is now maintained as a portfolio artifact. Its purpose is to show early hands-on Android experience with Java, Android services, SQLite persistence, and native Android UI resources.

## Historical Context

The project predates several major shifts in Android development:

- Gradle becoming the standard Android build system.
- AndroidX replacing the old Android Support Library.
- Modern Android privacy restrictions around clipboard access.
- Architecture Components, Room, ViewModel, and lifecycle-aware UI patterns.
- Current Play Store target SDK requirements.

For that reason, the repository is best read as a legacy project with added professional documentation, not as a current production-ready Android app.

## Current Goal

The current goal is repository hygiene and presentation:

- Explain what the project does.
- Preserve the original implementation.
- Document known limitations honestly.
- Show how the project could be modernized in the future.
