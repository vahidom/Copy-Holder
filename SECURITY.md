# Security Policy

## Project Status

Copy Holder is a legacy portfolio project and is not actively maintained as production software.

## Supported Versions

No versions are currently supported for security updates.

## Security Notes

This application stores clipboard text locally in SQLite. Clipboard content can contain sensitive information such as passwords, tokens, personal messages, or verification codes.

Because this project targets old Android APIs and predates modern Android clipboard privacy restrictions, it should not be used as a secure clipboard manager on current devices.

## Reporting

If you notice a security concern in this repository, please open a GitHub issue with a clear description. For sensitive reports, please contact me privately through the contact information listed on my GitHub profile.
